# Saves

A save is the whole simulation state as plain JSON (`src/sim/save.ts`):

- **Version.** Every save carries `version` (today 31: version 31 added traditions (each settlement's craft and why it holds to its ways; an older save's settlements keep their customs, feasts and names, and take up a craft as they go), version 30 added renewal (each workplace's idle clock, the building a site is built to take over from, each planner's clock for looking over what it has built; buildings pulled down and moved out in the stats), version 29 added ships (whether they are on, every boat of every settlement's fleet with its name, crew and the settlement a founding party's boat is bound for, and when each settlement's people last stayed ashore for want of one; boats built, boat trips and trips not made in the stats), version 28 added conveyors (the world's belt tiles and their count, the loads riding them, each settlement's belts and its clock for laying them; belts laid, loads and goods carried and their seconds in the stats), version 27 added the sea's shallows and reefs (a tile grid; an older world has neither) and charts (whether they are on, each settlement's charted islands, look-out clock, wish to explore and last voyage; voyages and islands charted in the stats), version 26 added gifts to the barbarians (each camp's friend, goodwill and gift clock; gifts and settled barbarians in the stats), version 25 added naming customs (each settlement's custom and each villager's name; an older save's settlements take theirs from their land as it loads), version 24 added roads of stone (the world's route cost on stone and its count of stone tiles), version 23 added feasts (each settlement's feasts and until when the last lifts its mood; feasts held and missed), version 22 added ox carts (trips set out, and the long-haul goods carried by ox cart with their seconds), version 21 added farms that grow (each building's further hands, its size, the farm new fields grow, what it has made, and when a home last ate each food; meals eaten and fields laid), version 20 added which way each building faces, version 19 a cart's round of further drops, version 18 when each settlement first chose to trade for a good rather than make it, version 17 added paths and roads (what was the road cost is the path cost, each settlement's roads, the world's count of road tiles, and what each delivery has walked on roads and paths), version 16 added hardship (each building's fire, flood and sickness, the barbarians' camps, each settlement's laws and when each hazard last struck it), version 15 added each settlement's age, version 14 added whether each settlement was founded across water, version 13 added settling (each settlement's mother and when it last sent settlers), version 12 added carts (who has one out, how far each settlement's deliveries go, long hauls counted), version 11 added who went to school and each library's copying clock, version 10 added people (ages, skills, each settlement's custom and its dead waiting for their farewell), version 9 added trade, each settlement's trade ledger and what its planner wants and uses, version 8 added seasons, homes' firewood and how long a workplace has stood full, version 7 homes' comforts, tools wearing out and spoiled food, version 6 the steward's levers, zones and the chronicle, version 5 districts, streets and replanning, version 2 added the planner's memory of where it found no room, version 3 each building's "no way in" time, version 4 terrain, deposits, worn paths, bridges, being fed apart from mood and delivery times; a version 3 world loads flat, with nothing in the ground). Each later change to the state's shape raises it and adds a migration that upgrades a save of the version before, with a test that loads a fixture saved at the old version (`tests/fixtures/save-v<n>.json`). A save from a newer game than the one running is refused with a message, never half-loaded.
- **Content.** The design bundle is not saved. A save records the hash of the bundle it was made with and is loaded against the one the game runs, so a balance change applies to games already under way.
- **What goes in.** The random streams (`rng`, and `krng` for [knowledge](/systems/knowledge.md)) are plain numbers; references between agents and buildings become ids; tile grids are run-length encoded. A carrier's job can still point at a building demolished under it, so those are kept too. A small island game is about 60 KB.
- **Exact.** A loaded game plays on exactly as the original would have: [Gate 6](/gates/06-solid-ground.md) saves a two-settlement game halfway, loads it from the JSON text and requires the same end state and receipt as a game that never stopped.

In the browser the game autosaves every 20 seconds of play, when the tab is hidden or closed, and when a new world is started; the new-game screen offers **Continue** when an autosave exists. The menu can download the game as a file and load one back.
